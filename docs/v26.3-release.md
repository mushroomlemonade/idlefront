# IdleFront v26.3

Release scope: native fleet replenishment and standing orders, explicit/automatic
idle mode, live cinematic tracking, compact defense controls, mobile slider and
radial-menu polish, and the accumulated nation naval pacing changes.

## UI consolidation

- Landing version is v26.3. Existing v26.2 identity synchronization is retained.
- Fleet size reuses the population slider rather than introducing another bar
  implementation. Slider and fleet styles load once from shared CSS modules.
- Fleet and ongoing fronts are sibling sections. Alert controllers move into
  the fronts section without duplication and return to their original location
  when it closes. Existing theme surface/text/border tokens are reused.
- The obsolete separate fleet settings dialog is removed; the command-bar idle
  action remains. Fleet target defaults to zero with automatic owned-port use.
- Ports/escort/patrol share one animated, keyboard-accessible segmented control.
- Drag hit areas stay inside the size control; fill and pointer use the same
  geometry. Release snaps to whole ships; reduced-motion preferences are honored.
- Idle names, flags and status symbols share bounded sizing and camera-relative
  placement. Normal-play label sizing is unchanged.

  texture URLs resolved at runtime. The referenced textures exist in resources.

## Deployment and limits

Push destination is **mushroomlemonade/idlefront main**, not the upstream project.
Production uses its existing main pull/build cycle. Git push confirmation is not
live-deployment confirmation. No database migration or forced match termination
is part of this release operation.

The owner has iteratively playtested on iPhone. This release audit does not claim
fresh physical-device validation, pixel-perfect parity on all screens, large-map
performance certification, or exhaustive live multi-device recovery coverage.
MIRV shot grouping remains proximity-based. Manual ship commands take precedence;
fleet automation steers automation-built ships, not every manually built ship.
