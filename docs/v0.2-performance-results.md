# v0.2 discovery performance — September 10, 2026

Development measurements, not release certification. Reports are local `.data/*.json` artifacts; reproduce with `scripts/benchmark-uhd-world.ts`.

All runs below used PixelEarth27v1 (21,344 × 10,124 tiles), 2,000 bots, one human, normal attack divisor 1, and 5× trade/train presets. Simulations run in isolated processes, not live saved worlds. Warm-up ticks through 301 are excluded. No GPU/browser timings are included.

| Run | Ticks | Mean simulation ms | p95 ms | Notes |
| --- | ---: | ---: | ---: | --- |
| `fog27-baseline-first.json` | 650 | 76.98 | 95.93 | No fog/activity approximation; idle human |
| `fog27-activity-first.json` | 650 | 34.97 | 43.92 | First 1-Hz remote frontier tier; idle human |
| `fog27-active-human.json` | 950 | 43.64 | 60.31 | Human repeatedly attacks wilderness |
| `fog27-profile.json` | 1,400 | 57.57 | 81.14 | CPU-profiled run; active human |
| `fog27-bounded-frontiers.json` | 3,000 | 71.08 | 143.99 | Remote budget 64, but every city owner woke fully |
| `fog27-interaction-frontiers.json` | 3,000 | 31.15 | 40.02 | Interaction-based activation removes first-city cliff |

The last pair is the useful longer comparison. It changes which isolated bot fronts use the approved approximation; identical outcomes are NOT claimed. The earlier 650-tick baseline cannot establish a precise percentage gain for a later 3,000-tick workload.

Latest 3,000-tick run: 61 samples exceeded 100 ms, maximum 164.49 ms, peak RSS about 2,008 MiB. The human owned 41,694 tiles; there were 107 cities and three transports at the end. Fog advance averaged 0.019 ms; participant projection/encoding averaged 0.737 ms. Final participant snapshot: 368,496 bytes, 15.02 ms preparation. No ports, factories, trains or mature trade fleets existed in that run, so it does NOT validate high-traffic late play.

The CPU profile still places attack expansion, terrain/frontier lookups, BFS and contact maintenance near the top. The low-cost fog shader is not a server TPS optimization; the server saving comes from explicitly reduced isolated bot frontier work. All unit movement, structures, income and human-involving land actions retain their ordinary simulation clocks.

Example reproduction (PowerShell):

```powershell
$env:IDLE_BENCH_FOG='1'
$env:IDLE_BENCH_BOT_ACTIVITY='1'
$env:IDLE_BENCH_ATTACK_DIVISOR='1'
$env:IDLE_BENCH_HUMAN_ATTACKS='1'
node --import tsx scripts/benchmark-uhd-world.ts resources/maps/pixelearth27v1 .data/new-fog-report.json 3000
```
